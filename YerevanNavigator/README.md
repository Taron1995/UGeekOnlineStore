# Երևան Նավիգատոր 🧭

Հեռախոսի համար նավիգատոր՝ Երևանի քարտեզով։ Աշխատում է որպես վեբ-հավելված (PWA) — տեղադրում App Store / Play Market պետք չէ, բավական է բացել բրաուզերում և «Ավելացնել գլխավոր էկրանին»։

## 📴 Աշխատում է առանց ինտերնետի
Ինտերնետ պետք է **միայն առաջին բացման ժամանակ**, երբ Երևանի քարտեզը պահվում է հեռախոսում։ Դրանից հետո ամեն ինչ աշխատում է հեռախոսի ներսում.

| Ինչ | Ինչպես է աշխատում offline |
|---|---|
| Քարտեզ | Հավելվածն ինքն է նկարում փողոցները, շենքերը, այգիները, գետը և փողոցների անունները |
| Երթուղի | Ճանապարհների ցանցի վրա A* ալգորիթմ, միակողմանի փողոցներ, շրջանաձև հրապարակներ, մի քանի միլիվայրկյանում |
| Որոնում | Փողոցներ, հասցեներ («Մաշտոց 5»), վայրեր (դեղատուն, թատրոն…) հայերեն, ռուսերեն, լատինատառ (tumanyan) |
| GPS | Արբանյակային է, ինտերնետ չի պահանջում |

Եթե ինտերնետ կա, կարելի է միացնել նաև OSM-ի սովորական քարտեզը (ձախ ներքևի կոճակ)։

## Հնարավորություններ
- **Ճշգրիտ GPS** — `enableHighAccuracy`, ճշգրտության շրջան, վատ (Wi‑Fi/բջջային) կոորդինատների զտում, աղմուկի հարթեցում, կետի «կպցում» երթուղուն
- **Կողմնացույց** — սլաքը ցույց է տալիս ուղղությունը նաև կանգնած ժամանակ
- **Երթուղի** մեքենայով / ոտքով / հեծանիվով
- **Քայլ առ քայլ ցուցումներ հայերենով** — «200 մ հետո թեքվեք աջ դեպի Մաշտոց», մնացած հեռավորություն և ժամանակ
- **Ավտոմատ վերահաշվարկ**, երբ շեղվում եք երթուղուց
- **Ձայնային ուղեցույց** (🔊, եթե հեռախոսն ունի հայերեն ձայն)
- Էկրանը չի անջատվում նավիգացիայի ժամանակ

## Քարտեզի տվյալները
`data/` պանակի ֆայլերը ստեղծվում են OpenStreetMap-ից `tools/build-offline-data.mjs` սկրիպտով։
GitHub Actions-ը (`.github/workflows/yerevan-offline-data.yml`) այն գործարկում է ավտոմատ՝
սկրիպտը փոխելիս և ամիսը մեկ անգամ (քարտեզը թարմ պահելու համար), և պահպանում արդյունքը ռեպոզիտորիայում։
Ձեռքով՝ GitHub → Actions → «Yerevan Navigator offline data» → Run workflow, կամ ինտերնետով համակարգչում՝
```bash
node YerevanNavigator/tools/build-offline-data.mjs
```

## Գործարկում
GPS-ը բրաուզերում աշխատում է **միայն HTTPS-ով**։ Ամենահեշտ տարբերակը՝ GitHub Pages.

1. GitHub-ում՝ **Settings → Pages → Deploy from a branch**, ընտրեք ճյուղը և `/ (root)`
2. Բացեք հեռախոսում `https://<username>.github.io/<repo>/YerevanNavigator/`
3. Թույլ տվեք տեղորոշումը, ապա բրաուզերի մենյուից՝ «Add to Home screen»

Համակարգչում փորձարկելու համար՝
```bash
cd YerevanNavigator && python3 -m http.server 8080
```
և բացեք `http://localhost:8080` (localhost-ը համարվում է անվտանգ)։

## Ճշգրտության խորհուրդներ
- Հեռախոսի կարգավորումներում միացրեք **Precise / Ճշգրիտ տեղորոշում**
- Մեքենայում պահեք հեռախոսը առջևի ապակու մոտ
- Կողմնացույցը շեղվելու դեպքում հեռախոսով «8» պատկերեք օդում
