# Երևան Նավիգատոր 🧭

Հեռախոսի համար նավիգատոր՝ Երևանի քարտեզով։ Աշխատում է որպես վեբ-հավելված (PWA) — տեղադրում App Store / Play Market պետք չէ, բավական է բացել բրաուզերում և «Ավելացնել գլխավոր էկրանին»։

## Հնարավորություններ
- **Երևանի քարտեզ** (OpenStreetMap), սահմանափակված քաղաքի տարածքով
- **Ճշգրիտ GPS** — `enableHighAccuracy`, ճշգրտության շրջան, վատ (Wi‑Fi/բջջային) կոորդինատների զտում, աղմուկի հարթեցում (Kalman), կետի «կպցում» երթուղուն
- **Կողմնացույց** — սլաքը ցույց է տալիս ուղղությունը նաև կանգնած ժամանակ (iOS և Android)
- **Հասցեի որոնում** հայերեն/ռուսերեն/անգլերեն (Nominatim), կամ պարզապես սեղմեք քարտեզի վրա
- **Երթուղի** մեքենայով / ոտքով / հեծանիվով (OSRM)
- **Քայլ առ քայլ ցուցումներ հայերենով** — «200 մ հետո թեքվեք աջ դեպի Մաշտոց», մնացած հեռավորություն և ժամանակ
- **Ավտոմատ վերահաշվարկ**, երբ շեղվում եք երթուղուց
- **Ձայնային ուղեցույց** (🔊 կոճակ, եթե հեռախոսն ունի հայերեն ձայն)
- Էկրանը չի անջատվում նավիգացիայի ժամանակ (Wake Lock)
- Դիտված քարտեզի սալիկները պահվում են քեշում՝ թույլ ինտերնետի դեպքում

## Գործարկում
GPS-ը բրաուզերում աշխատում է **միայն HTTPS-ով**։ Ամենահեշտ տարբերակը՝ GitHub Pages.

1. GitHub-ում՝ **Settings → Pages → Deploy from a branch**, ընտրեք ճյուղը և `/ (root)`
2. Բացեք հեռախոսում `https://<username>.github.io/<repo>/YerevanNavigator/`
3. Թույլ տվեք տեղորոշումը, ապա բրաուզերի մենյուից՝ «Add to Home screen»

Համակարգչում փորձարկելու համար՝
```bash
cd YerevanNavigator && python3 -m http.server 8080
```
և բացեք `http://localhost:8080` (localhost-ը համարվում է անվտանգ)։

## Ճշգրտության խորհուրդներ
- Հեռախոսի կարգավորումներում միացրեք **Precise / Ճշգրիտ տեղորոշում**
- Մեքենայում պահեք հեռախոսը առջևի ապակու մոտ
- Կողմնացույցը շեղվելու դեպքում հեռախոսով «8» պատկերեք օդում

## Ֆայլեր
| Ֆայլ | Նշանակություն |
|---|---|
| `index.html` | Էջը |
| `app.js` | Քարտեզ, GPS, որոնում, երթուղի, ցուցումներ |
| `style.css` | Բջջային դիզայն |
| `sw.js` | Offline քեշ |
| `manifest.json`, `icon.svg` | PWA տեղադրում |

Օգտագործվող անվճար ծառայությունները (OSM, Nominatim, OSRM) ունեն օգտագործման սահմանափակումներ. մեծ ծանրաբեռնվածության դեպքում պետք է սեփական սերվեր։
